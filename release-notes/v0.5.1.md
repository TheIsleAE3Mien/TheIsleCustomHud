# TheIsleVNHud v0.5.1

> [!NOTE]
> **Đây là bản generic dành cho mọi server.** Bản này không chứa GameMonitoring Server ID, không gọi API thông tin server và không hiện widget tên server/player online.

## Điểm mới

- Sửa HUD tự tắt khi Windows tạm chuyển foreground qua Task Switching, remote-session toolbar hoặc một cửa sổ trung gian trong lúc The Isle vẫn đang chạy.
- F8 chỉ bật/tắt dashboard; các widget HUD tiếp tục hiển thị theo cửa sổ game.
- Thêm bộ lọc dùng chung cho Radar và Compass: Khu bảo tồn, vùng Di cư, vùng Tuần tra, địa điểm khác và bạn bè.
- Tối ưu async/background worker cho live WebSocket và Compass, giảm render, polling và ghi file không cần thiết.
- Cải thiện đăng nhập Steam, nhận diện The Isle, fullscreen/borderless và lưu cấu hình HUD.
